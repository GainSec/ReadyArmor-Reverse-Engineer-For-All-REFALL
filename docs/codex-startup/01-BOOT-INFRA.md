# Start infrastructure

1. Complete the installation procedure.
2. Configure Agent Canvas/OpenHands and the provider CLI.
3. Start the backend with `python -m arctic_base`.
4. Read `/api/health`.
5. Read `/api/refall/ops/status`.
6. Examine the configured execution resources.

The development backend command is also `uv run arctic-base` from `arcticbase/backend`.
Use the deployment service configuration when the backend runs as a managed service.
