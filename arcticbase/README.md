# REFALL AB workbench component

This directory contains the REFALL AB backend and web interface.
The backend derives from [ArcticBase](https://github.com/GainSec/ArcticBase).
REFALL extensions provide subjects, coverage, evidence, capabilities, operations, and reports.

## Contents

| Directory | Contents |
| --- | --- |
| `backend/` | FastAPI service, storage models, and API routes. |
| `frontend/` | Svelte web interface. |
| `docs/` | Component documentation. |

Read [API reference](../docs/api.md) for the REFALL route map.
Read [Deployment](../deploy/README.md) for Docker Compose instructions.
