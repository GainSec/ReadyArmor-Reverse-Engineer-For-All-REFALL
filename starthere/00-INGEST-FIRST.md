# Manager startup order

1. Read the repository agent instructions.
2. Read the installation and configuration guides.
3. Examine infrastructure health.
4. Select the subject and source path.
5. Read the stored subject context.
6. Examine coverage, pending actions, and capabilities.

Do not start the loop before stored context exists.
Use `REFALL_PUBLIC_BASE_URL` for API requests.
Set `SUBJECT` to the subject slug.
Set `SOURCE_PATH` to an absolute path visible to the backend.
